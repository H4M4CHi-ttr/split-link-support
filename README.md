# Split Link サポート

![Split Link のアイコン](assets/split-link-icon.png)

Split Link の質問・機能リクエスト・バグ報告を受け付ける公開リポジトリです。

[Chrome ウェブストアで Split Link を見る](https://chromewebstore.google.com/detail/split-link/aoppkblngfgfaaiopijjgleohngggchc)

## GitHub で問い合わせる

[問い合わせを作成する](https://github.com/H4M4CHi-ttr/split-link-support/issues/new/choose)から、内容に合ったテンプレートを選んで投稿してください。投稿には GitHub アカウントが必要です。

- **質問**：使い方や設定についての相談
- **機能リクエスト**：追加してほしい機能や改善の提案
- **バグ報告**：期待どおりに動かない場合の報告

投稿前に、同じ内容の[既存の Issue](https://github.com/H4M4CHi-ttr/split-link-support/issues)がないか確認してください。バグ報告には、Split Link と Chrome のバージョン、OS、再現手順、期待した動作と実際の動作を添えると調査に役立ちます。

投稿は公開されます。個人情報・パスワード・認証情報を含めず、画像や URL にも公開したくない情報が写っていないか確認してください。

## Chrome ウェブストアからも問い合わせできます

Chrome ウェブストアの[サポートページ](https://chromewebstore.google.com/detail/split-link/aoppkblngfgfaaiopijjgleohngggchc/support)でも、質問・提案・問題報告を送れます。利用しやすい窓口を選んでください。

## このリポジトリについて

このリポジトリはサポート受付専用です。拡張機能のソースコードや配布ファイルは置いていません。
